# تطبيق العد التنازلي – عين مكة (Xiaomi TV / Android TV)

التطبيق عبارة عن WebView بيعرض الصفحة من جوه التطبيق نفسه (بدون إنترنت)، والخط والشعار متضمنين.

## الريموت
- **OK** (أو زر القائمة): فتح شاشة تغيير التاريخ المستهدف
- **الأسهم**: التنقل بين الخانات، و**OK** على ▲ / ▼ للتغيير
- **Back**: إغلاق الشاشة، وضغطة تانية للخروج من التطبيق

## طريقة 1: بدون تثبيت أي برامج (GitHub)
1. اعمل حساب مجاني على github.com وأنشئ Repository جديد.
2. ارفع **محتويات** هذا المجلد (مش المجلد نفسه) بحيث يظهر `app` و`.github` في أول الصفحة.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد دقيقتين تقريباً نزّل **AinMakkah-TV-apk** من أسفل صفحة التشغيل، وفك الضغط للحصول على `app-debug.apk`.

## طريقة 2: Android Studio
افتح المجلد من File ← Open، استنى Sync، ثم Build ← Build APK(s).
الملف هيكون في `app/build/outputs/apk/debug/app-debug.apk`.

## تثبيت الـ APK على تلفزيون شاومي
1. من إعدادات التلفزيون: Device Preferences ← Security & restrictions ← **Unknown sources** (اسمح للمتصفح أو مدير الملفات).
2. انقل الملف بأي طريقة:
   - فلاشة USB + تطبيق مدير ملفات (مثل File Commander / X-plore)
   - أو تطبيق **Send Files to TV** على الموبايل والتلفزيون
   - أو ADB: `adb connect IP_التلفزيون` ثم `adb install app-debug.apk`
3. هتلاقي التطبيق في قائمة التطبيقات باسم "العد التنازلي – عين مكة".
