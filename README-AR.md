# تطبيق العد التنازلي – عين مكة (Xiaomi TV / Android TV)

التطبيق عبارة عن WebView بيعرض الصفحة من جوه التطبيق نفسه (بدون إنترنت)، والخط والشعار متضمنين.

## الريموت
- **OK** (أو زر القائمة): فتح شاشة تغيير التاريخ المستهدف
- **الأسهم**: التنقل بين الخانات، و**OK** على ▲ / ▼ للتغيير
- **Back**: إغلاق الشاشة، وضغطة تانية للخروج من التطبيق

## طريقة 1: بدون تثبيت أي برامج (GitHub)
1. اعمل حساب مجاني على github.com وأنشئ Repository جديد.
2. ارفع **محتويات** هذا المجلد (مش المجلد نفسه) بحيث يظهر `app` و`.github` في أول الصفحة.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد دقيقتين تقريباً نزّل **AinMakkah-TV-apk** من أسفل صفحة التشغيل، وفك الضغط للحصول على `app-debug.apk`.

## طريقة 2: Android Studio
افتح المجلد من File ← Open، استنى Sync، ثم Build ← Build APK(s).
الملف هيكون في `app/build/outputs/apk/debug/app-debug.apk`.

## تثبيت الـ APK على تلفزيون شاومي
1. من إعدادات التلفزيون: Device Preferences ← Security & restrictions ← **Unknown sources** (اسمح للمتصفح أو مدير الملفات).
2. انقل الملف بأي طريقة:
   - فلاشة USB + تطبيق مدير ملفات (مثل File Commander / X-plore)
   - أو تطبيق **Send Files to TV** على الموبايل والتلفزيون
   - أو ADB: `adb connect IP_التلفزيون` ثم `adb install app-debug.apk`
3. هتلاقي التطبيق في قائمة التطبيقات باسم "العد التنازلي – عين مكة".

## تعديل التاريخ الافتراضي من الكود
الملف `app/src/main/assets/www/index.html` ← السطر `var DEFAULT="2027-02-24T00:00"`.

## توقيع ثابت للتحديثات (مرة واحدة)
عشان التحديثات تنزل فوق النسخة المثبتة بدون حذف، لازم كل بناء يتوقع بنفس المفتاح:
1. انسخ ملف المفتاح `debug.keystore` (من `C:\Users\<اسمك>\.android\debug.keystore`).
2. حوّله لنص: في PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("debug.keystore")) | Set-Clipboard`
3. في GitHub: Settings ← Secrets and variables ← Actions ← أضف:
   - `KEYSTORE_B64` = النص اللي نسخته
   - `KEYSTORE_PASS` = `android`
   - `KEY_ALIAS` = `androiddebugkey`
   - `KEY_PASS` = `android`
4. شغّل Build APK من جديد.

## منع إطفاء الشاشة على التلفزيون
التطبيق نفسه بيمنع الشاشة من الإطفاء طول ما هو مفتوح، ولو فيه إعدادات نظام تطفي التلفزيون أو الشاشة، لازم تعطّلها من إعدادات الجهاز:
- **Sleep / Auto standby / Auto power off** (إيقاف تلقائي): خليها Never أو أطول وقت.
- **Screen saver** (شاشة التوقف): خليها Never.
- **Power saving** (توفير الطاقة): عطّله لو موجود.
- التطبيق بيعيد تحميل نفسه كل 6 ساعات بهدوء (بدون ما يضيع الإعدادات) عشان يفضل سريع لو اشتغل أيام طويلة.

## فتح التطبيق تلقائياً بعد تشغيل التلفزيون
التطبيق بيفتح لوحده أول ما الجهاز يشتغل. لو ما اشتغلش:
- من إعدادات الجهاز ابحث عن **Autostart** أو **Auto start** أو **Startup** (غالباً في Security أو Apps)، وفعّله لتطبيق "العد التنازلي – عين مكة".
- لو الجهاز بيفتح على شاشة الصفحة الرئيسية بدل التطبيق، تأكد إن الإعدادات فوق ما اتغيرت.
